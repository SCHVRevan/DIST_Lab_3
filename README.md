# DIST_Lab_3
# Лабораторная работа: Защита процесса от DLL-инъекций с использованием UpdateProcThreadAttribute

## Описание
В данной работе реализован механизм защиты собственного процесса от несанкционированной загрузки (инъекции) сторонних DLL. Защита достигается путём перезапуска текущего процесса с применением политики митигации, которая блокирует загрузку DLL, не подписанных Microsoft, с использованием функции UpdateProcThreadAttribute.

## Состав проекта

- **DefProcess.cpp**  
  Исходный код защиты процесса.  
  - При запуске без аргумента (например, `1234`) процесс определяет, что защита не активирована, и перезапускает себя с дополнительным аргументом.
  - При запуске с аргументом защиты (например, `"1234"`) процесс работает в защищённом режиме, переходя в бесконечное ожидание (WaitForSingleObject), чтобы предотвратить завершение.

- **CreateProcessWithBlockDllPolicy**  
  Функция, реализующая создание нового процесса с установленной политикой митигации через расширенные атрибуты (STARTUPINFOEX и UpdateProcThreadAttribute).  
  - Политика `PROCESS_CREATION_MITIGATION_POLICY_BLOCK_NON_MICROSOFT_BINARIES_ALWAYS_ON` блокирует загрузку DLL, неподписанных Microsoft.

## Сборка

### С использованием MinGW (GCC)

1. Откройте командную строку и перейдите в директорию с исходным кодом:
2. Скомпилируйте исполняемые файлы. Пример:
    ```bash
    g++ -static DefProcess.cpp -o DefProcess.exe
3. Скомпилируйте файлы библиотек. Пример:
   ```bash
    g++ -static -shared VirusDLL.cpp -o VirusDLL.exe

## Запуск
1. Запустите созданный исполняемый файл DefProcess.exe без параметров:
    ```bash
    DefProcess.exe
2. Программа определит, что защита не активирована, и перезапустит себя с параметром (например, 1234).

3. В защищённом режиме процесс выполняется с примененной политикой, блокирующей загрузку неподписанных DLL.
    - Защищённый процесс переходит в состояние ожидания, что предотвращает его завершение и позволяет проверить работу защиты (например, попытки инъекции DLL будут отклонены).

## Защита
- Защита реализована с помощью функций Windows API. Обратите внимание, что она применяется только к процессам, создаваемым через CreateProcessA() с использованием расширенных атрибутов.

- Некоторые системные компоненты (например, DLL, подписанные Microsoft) могут быть загружены, даже если защита активна.
